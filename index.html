How to read this site

Status is part of the result

Every public claim should carry a visible research status. A numerical pass is not a theorem; an internally consistent model is not experimental evidence; a failed branch stays visible when it constrains the next move.

NUMERICAL PASS

Reproduced calculation

A result that survives the stated numerical gates and refinements within a specified model.

OPEN

Unresolved physics

A target or mechanism not yet derived from the parent assumptions.

FAIL / RETIRED

Rejected route

A branch that violated a gate, became non-novel, or no longer supports the physical interpretation.
